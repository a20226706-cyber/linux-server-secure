Proyecto personal

Red empresarial con respaldo OSPF

Diseño y configuración de una red empresarial segmentada mediante VLANs, enlaces trunk y enrutamiento inter-VLAN. Implementé DHCP para asignación automática de direcciones y ACLs para controlar el acceso entre áreas.

Conecté dos sedes mediante OSPF. Al desconectar el enlace principal, verifiqué con tracert que la sucursal llegaba al servidor por el enlace de respaldo. Al restaurarlo, confirmé en la tabla de rutas que OSPF volvía a elegir el principal.
